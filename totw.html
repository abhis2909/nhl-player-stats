Each position's pick is whoever rated highest, among players with at least one game that week, using the same percentile-based rating engine as Player Cards and Range Ratings — just scored against that single week's stat delta instead of the season. A finished week (one with a snapshot both at its start and its end) is computed once and stored permanently, so it stays put even if older raw snapshots later get pruned; the current in-progress week is always recomputed live against Live data. Data via the unofficial NHL API.
